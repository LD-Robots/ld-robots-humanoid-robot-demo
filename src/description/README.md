# Description Subsystem

Robot model definitions and visualization.

## Packages

- **humanoid_description** - Main URDF/Xacro robot model with sensors

## Future Packages

- **humanoid_meshes** - 3D meshes for visual/collision geometry
- **humanoid_materials** - Material definitions and textures
- **humanoid_variants** - Alternative robot configurations
- **humanoid_tools** - URDF validation and conversion tools
